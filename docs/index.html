Architecture

This project uses a decentralized broadcast architecture. Instead of a central server, events are propagated through the browser environment using the BroadcastChannel API.

Note: example_output acts as an external event provider (broadcaster), while the files in /src act as listeners (overlays).

All overlays in this project automatically remap global desktop coordinates to their local viewport using the desktop_bounds broadcast, ensuring pixel-perfect alignment regardless of your OBS canvas size.

Input Messages (External API)

The following messages are expected from external providers (e.g., Python scripts or the example_output monitor tools):

mouse_move BroadcastChannel

Triggered on every cursor movement.

{
  "x": number, // Desktop X coordinate
  "y": number  // Desktop Y coordinate
}
mouse_click BroadcastChannel

Triggered on mouse button press/release.

{
  "button": "MB1" | "MB2" | "MB3",
  "pressed": boolean,
  "x": number,
  "y": number
}
keyboard_event BroadcastChannel

Triggered on key presses.

{
  "key": string // e.g. "a", "+", "-", "Shift"
}
desktop_bounds BroadcastChannel

Used to sync monitor dimensions for remapping.

{
  "minX": number,
  "maxX": number,
  "minY": number,
  "maxY": number
}

Detailed documentation for the internal logic of the /src components.

Astro Bee (astroBee_Sketch.js)

Member Type Description
beeModel p5.Geometry The 3D model instance loaded from bee.obj.
targetX / Y number The mouse position in 3D space coordinates.
zoom number Current scale factor (interpolated).
triggerClickEffect() function Triggers a random rotation burst.
updateZoom(delta) function Increments or decrements the target scale.

Magic Wand (Star Class)

The Star class manages individual particle simulations.

Method Description
update() Calculates physics (acceleration, velocity, position) and decrements life.
display() Renders the star with a shadowBlur effect for a "glowing" look.
finished() Returns true when life < 0.

Developer Guide

The code in /src is organized into:

  • HTML Wrappers: Handle the BroadcastChannel boilerplate and coordinate remapping.
  • Sketches (src/sketch/): Contain the visual logic (p5.js).
  • Patches (src/patches/): Contain exported Cables.gl WebGL simulations.

To create a new overlay, copy the listener logic from src/astro_bee.html and integrate your own rendering loop.
